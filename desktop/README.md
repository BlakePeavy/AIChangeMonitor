# Change Monitor desktop

Tauri 2 window around the existing Go engine. See [DESKTOP.md](DESKTOP.md) (also at the repo root).

Quick start: build the sidecar with scripts/build-sidecar.py (or scripts/build-sidecar.ps1 on Windows), then cargo tauri dev. First launch uses File then Open repo.

The Go CLI at the repo root is not replaced.
